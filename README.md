# My certifications block for Moodle™ LMS

[![MDL Shield](https://img.shields.io/endpoint?url=https%3A%2F%2Fmdlshield.com%2Fapi%2Fbadge%2Fblock_mucertify_my)](https://mdlshield.com/plugins/block_mucertify_my) ![Moodle Plugin CI](https://github.com/mutms/moodle-block_mucertify_my/actions/workflows/moodle-ci.yml/badge.svg) [![camp](https://camp-registry.org/badge/block_mucertify_my.svg)](https://camp-registry.org/plugin/block_mucertify_my.html)

Optional block for the [Certifications plugin](https://github.com/mutms/moodle-tool_mucertify)
— fully open source under GPL 3.0. Part of the [MuTMS suite](https://github.com/mutms).

## Requirements

> This plugin is included in the [MuTMS distribution](https://github.com/mutms/mutms) —
> no manual installation needed if you use the distribution.

Required plugins:

* [Additional tools library plugin](https://github.com/mutms/moodle-tool_mulib)
* [Certifications plugin](https://github.com/mutms/moodle-tool_mucertify)

## Documentation

See [online documentation](https://docs.mutms.org/mucertify/) for more
information.
